Κεφάλαιο 4: Βασικές Αρχές Αλγορίθμων

Ένας αλγόριθμος είναι μια πεπερασμένη σειρά ενεργειών, αυστηρά καθορισμένων και εκτελέσιμων σε πεπερασμένο χρόνο, που στοχεύουν στην επίλυση ενός προβλήματος.

4.1 Θεμελιώδη Κριτήρια Αλγορίθμου

Κάθε αλγόριθμος οφείλει να πληροί αυστηρά τα ακόλουθα 5 βασικά κριτήρια:

  • Είσοδος (Input): Καμία, μία ή περισσότερες τιμές εισόδου.
  • Έξοδος (Output): Τουλάχιστον μία τιμή αποτελέσματος.
  • Καθοριστικότητα (Definiteness): Κάθε εντολή πρέπει να διατυπώνεται με απόλυτη σαφήνεια.
  • Πεπεραστικότητα (Finiteness): Υποχρεωτικός τερματισμός μετά από πεπερασμένο αριθμό βημάτων.
  • Αποτελεσματικότητα (Effectiveness): Κάθε εντολή πρέπει να είναι απλή και εκτελέσιμη.

4.2 Ανάλυση Πολυπλοκότητας

Η χρονική πολυπλοκότητα εκφράζεται με τον συμβολισμό Big-O: $\mathcal{O}(n)$, $\mathcal{O}(n \log n)$ και $\mathcal{O}(n^2)$. Για αναδρομικούς αλγορίθμους όπως το Merge Sort, η σχέση περιγράφεται από την εξίσωση:

$$T(n) = 2T(n/2) + \mathcal{O}(n) \implies T(n) = \mathcal{O}(n \log n)$$

4.3 Ψευδοκώδικας Αναζήτησης

function binarySearch(A, target): low = 0, high = length(A) - 1 while low <= high: mid = floor((low + high) / 2) if A[mid] == target: return mid else if A[mid] < target: low = mid + 1 else: high = mid - 1 return -1

[Πηγή: Εισαγωγή στην Επιστήμη των Υπολογιστών, Τμήμα Πληροφορικής]
